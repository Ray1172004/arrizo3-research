# Chery Arrizo 3 OEM Head Unit Research

**Automotive infotainment reverse engineering — research in progress.**

The 2021 Chery Arrizo 3 is the target of a non-invasive research project. Analysis currently focuses on a separately published Tiggo 2 CheryLink reference update, not a firmware dump from the Arrizo 3.

Safety: no firmware flashing or exploitation on the installed vehicle, and no private keys, copyrighted firmware or sensitive device identifiers published.
