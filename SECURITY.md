# Security and coordinated disclosure

This is educational, non-invasive automotive reverse engineering. Do not use third-party update packages on the original Arrizo 3 head unit. No live-car exploitation, ECU modifications or CAN injection are performed.

Do not submit proprietary firmware, APKs, reusable ADB private keys, VIN/MachineID, private logs or unredacted screenshots in issues or commits. Potential vulnerabilities should be reported privately to the vendor with version-scoped evidence. Removing sensitive files from the latest commit does not remove them from Git history.
