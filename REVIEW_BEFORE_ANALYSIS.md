# Revisión antes de analizar / Review before analysis

**Español** · [English](#english)

## Español

Este repositorio publica investigación y scripts originales, **no** firmware ni herramientas de actualización propietarias. Los archivos de referencia corresponden a un **Tiggo 2** y no deben utilizarse para actualizar la pantalla del Arrizo 3.

- Mantén muestras, proyectos de Ghidra, volcados y registros en carpetas privadas fuera del repositorio.
- No ejecutes los ejecutables del fabricante ni los conectes al vehículo.
- Inspecciona las salidas de los scripts antes de compartirlas y elimina datos personales e identificadores.
- La existencia de una copia del firmware no significa que exista un procedimiento de recuperación probado.
- Antes de cada publicación revisa `git diff --cached`, `git status`, archivos y **historial Git**; `.gitignore` no impide publicar contenido ya rastreado.

## English

This repository publishes original research and scripts, **not** proprietary firmware or update executables. Reference samples were distributed for **Tiggo 2** and must never be used to update an Arrizo 3 head unit.

Keep Ghidra projects, dumps, logs and vendor samples outside the repository. Never execute vendor update programs or connect them to the vehicle. Review all outputs before sharing, and inspect the entire Git history for secrets. A backup is not proof of recoverability.
